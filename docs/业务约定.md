# 业务约定

时间统一为带时区的 ISO 8601，金额为人民币元，区间均左闭右开。works 的 annual_lux_hours 是逐件年度上限，瞬时 max_lux 独立生效；缺测上界按所在柜体 max_lux、下界按0计，不允许跨年度借用。readings 的 lux 是原始读数，校正为 lux*gain+offset，校正前的负值截到0。连接有效读数采用两端均值的区间照度；只有同柜、同设备有效期且间隔不超过 max_gap_minutes 才可连接。单点不外推。遮光区间优先于测量，置 exposure 为0。主题覆盖按场次主题逐一满足 min_items，替代必须命中 eligibility。取消费用在 cancel_before 之前为0，之后用 cancel_cost；已开幕场次不可取消。建议优先避免保护风险，其后最小化确认场次的撤约费用，最后最大化候选场次主题覆盖；同优先级可报告多个等价解，不要求任意编号胜出。

没有校正记录的仪器采用单位增益与零偏移；存在 supersedes 时按该记录声明的适用区间取代前记录，其他期间不受影响。以 issued_at 判断截至时点是否已知。展出日期跨日按当地实际小时计算，不把 end 所在日期再加一天。shows 中 venue_grade 未另列时均为 standard。actions 是独立的业务操作输入，不是分析结论。

所有 date 或 at 字段按其声明的当地日期或带时区时间解释，缺失值为 JSON null，空列表表示明确为空。记录编号只标识实体，不包含优先级。涉及历史截点时仅使用该截点已知事实，生效期间与获知时间分别按相应字段解释。不同情景不等于已经确认的实际业务操作。
