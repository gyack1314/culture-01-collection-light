# 巡展累积光暴露分析与借展承诺安排

本项目保存本地合成业务资料、输入约定、资料完整性检查，以及一套可重复使用的
分析能力：

* **藏品年度光暴露账户**：连接有效读数、扣除遮光、给出缺测上下界，并保留每一段
  额度来自哪些原始读数和校正记录；
* **各馆承诺与兑现说明**：已经答应各馆的主题内容还能否兑现、替代关系是否命中
  eligibility、哪些承诺未兑现；
* **可行调整方案**：在已有承诺、主题最低覆盖与藏品保护之间取舍，给出代价、冲突
  与等价解；
* **更正传播**：计量更正（补录校正）发出后，账户、方案与既有确认如何随之变化；
* **持续复核**：馆方确认后从确认继续，而不是把整轮巡展重新视为自由选择。

资料均为本地合成，不对应真实个人、企业、场馆或合同；原始数据不带分析结论。
业务含义见 [业务约定](docs/业务约定.md)，文件与字段见 [资料目录](docs/资料目录.md)。

## 环境

Python 3.11。安装固定依赖：

```sh
python -m pip install -r requirements.txt
python tools/inspect_inputs.py
python -m pytest -q
```

`tools/inspect_inputs.py` 只检查资料校验和、字段与主键；业务结果由本项目的
`loanlight` 包计算，不需要网络和账号。

## 快速开始

所有命令在项目根目录执行；`--as-of` 表示“截至该时点已知的事实”，必须带时区。

```sh
# 1. 查看某件藏品的年度账户（也可省略 --work 查看全部）
python -m loanlight account --work W017 --as-of 2026-06-05T10:00:00+08:00

# 2. 查哪些区间贡献了额度、哪些区间仍不确定（含端点读数与校正）
python -m loanlight segments --work W017 --as-of 2026-06-05T10:00:00+08:00

# 3. 查原始读数的校正明细（哪支仪器、哪条校正）
python -m loanlight readings --device D6 --as-of 2026-06-05T10:00:00+08:00

# 4. 各馆承诺与兑现情况
python -m loanlight commitments --as-of 2026-06-05T10:00:00+08:00

# 5. 调整方案（代价、冲突、等价解）
python -m loanlight plan --as-of 2026-06-05T10:00:00+08:00

# 6. 计量更正前后账户变化及其来源
python -m loanlight reconcile --work W017 \
  --before 2026-06-04T09:00:00+08:00 --after 2026-06-05T10:00:00+08:00

# 7. 记录馆方确认，再从确认继续下一轮
python -m loanlight confirm --show B-next --decision keep \
  --works W017,W020 --at 2026-06-04T09:00:00+08:00
python -m loanlight review --as-of 2026-06-05T10:00:00+08:00

# 8. 按 actions 时间线重放（更正何时到达、账户和方案如何变化）
python -m loanlight timeline --as-of 2026-06-05T10:00:00+08:00
```

所有查询命令都支持 `--json`，输出结构稳定，便于给其他系统或报告使用。

## 关键口径

| 事项 | 口径 |
| --- | --- |
| 光暴露 | 已连接区间的照度 × 实际展出小时数；运输与遮光不消耗额度 |
| 连接读数 | 同柜、同设备有效期、间隔不超过柜体 `max_gap_minutes`；照度取两端校正值均值；单点不外推 |
| 缺测 | 下界按 0，上界按柜体 `max_lux`；给出区间与小时数 |
| 剩余额度 | 只用上界计算；若上界已无法证明安全，可规划余额按 0 计，绝不把下界当余额 |
| 校正 | `max(0, lux) * gain + offset`；只在适用期间生效；`issued_at` 之前视为未知；`supersedes` 只在自身期间取代前记录 |
| 年度 | 按区间起点时区的日历年分别核算，不跨年借用 |
| 场次日数 | 按当地日期差，不把 `end` 所在日期再加一天 |
| 撤约费用 | 已确认场次在 `cancel_before` 之前为 0，之后为 `cancel_cost`；候选场次不构成承诺，放弃无费用；已开幕不可取消 |
| 替代 | 必须命中场次主题、馆方等级和借展期间的 `eligibility`；同一实物不能同时安排在两馆 |

## 输出能回答什么

* `account`：每件藏品的下界/上界、峰值、缺测与遮光小时数、按年度剩余额度，以及
  是否存在保护风险（例如更正后峰值超过瞬时上限）。
* `segments`：每段额度的起止、柜体、布展、照度、小时数、贡献额度，以及端点读数
  和校正记录。缺测段单独列出。
* `commitments`：各场馆的主题最低覆盖是否达到、承诺藏品是否兑现、替代关系与去向。
  未兑现的承诺不会被算作主题覆盖。
* `plan`：决策、代价、保护冲突、排期冲突、受影响馆方，以及同分等价解的数量和前
  若干个代表解。
* `reconcile`：下界/上界/峰值变化、新增已知校正、按柜体与校正记录归并的受影响区间。
* `timeline`：按 `actions` 重放；每个操作时点只使用当时已知的事实，列出新增校正、
  账户变化、方案变化，以及受该校正实际改写的藏品。
* `review`：把已确认场次分为“需要停止的未开展场次”“无法撤销的既成消耗”“仍可
  保持”，并说明失去保护依据的原因。

## 持续性工作流

1. **收到新读数或撤展记录**：直接重跑 `account` / `segments`；账户以 `--as-of` 截断，
   未发生的时段不会被提前计入。
2. **收到计量更正**：确认 `issued_at`，用 `reconcile` 比较更正前后；变化只会出现在
   更正声明的适用期间内。
3. **准备下一轮巡展**：先 `plan` 看可行方案与代价，再与馆方沟通。
4. **馆方确认调整**：用 `confirm` 追加一条确认记录（默认 `output/confirmations.jsonl`，
   已被 `.gitignore` 忽略）。
5. **再次收到更正**：用 `review` 复核既有确认。需要停止的未开展场次、无法撤销的既成
   消耗、仍可保持的场次会被分开列出，不会被默默改写。

`plan` 与 `review` 默认读取 `output/confirmations.jsonl`；可用 `--confirmations` 指向
其他路径。确认记录只追加不覆盖，同一场次以最后一条为准；每条记录带内容签名，可用于
核对确认后计划是否被改写。

## 候选场次的假设

资料没有给候选场次的照度与每日小时数。`plan` 默认假设候选场次按 `50 lx × 8 h/天`
安排，并把该假设写入输出。可用 `--candidate-lux`、`--candidate-daily-hours` 覆盖；
不同假设下结论不同，输出中始终显式记录实际使用的数值。

```

  timeutil.py    区间、日历年、场次日数
  data.py        读取资料、字段解释与引用校验
  calibration.py 校正生效期间、supersedes、截至时点已知性

  plan.py        承诺、替代、撤约费用、方案优化、确认后复核

  store.py       确认记录的保存、读取与签名
  cli.py         命令行入口
  render.py      文本与 JSON 输出
tests/
  test_inputs.py   资料完整性与主键
  test_exposure.py 账户、缺测、遮光、校正传播
  test_plan.py     跨馆轮换、承诺、确认、持续复核
  test_rules.py    用小型构造数据覆盖连接、年度、边界规则
  test_cli.py      命令行契约
```

## 示例解读

截至 2026-06-05（C02 更正已发出）时，W017 的已测暴露约 6313.8 lx·h，另有 1 小时
缺测（05-03 23:00–24:00，上界按柜体 100 lx 计 100 lx·h），年度上界约
6413.8 lx·h。其峰值校正后为 114.8 lx，已高于该藏品 80 lx 的瞬时上限。
在这一证据下，B 馆原定 2026-08-01 至 08-20 展出的 W017 需要 7600 lx·h，超过可用
上界（约 6436.2 lx·h）；`plan` 会给出以 W020 等合格藏品替代的方案，并标明需要 B 馆
确认；`review` 则把“B-next 已确认保留 W017”归为需要停止或重新协商的未开展场次，
同时把 A 馆已开幕的既成消耗单独保留。

另一个例子是 W006（C1 柜）：05-01 17:00 至 21:00 之间没有读数，空档超过 60 分钟
采样间隔，不能跨接；加上布展末小时 23:00–24:00，共 5 小时按缺测上界（0 到 100 lx）
计入。05-02 08:00–10:00 的 2 小时遮光则完全不消耗额度，也不计入缺测。
